## PART 3: INTENT TRACKING & LEARNING

### Backend Tracking (Non-intrusive):
```
UserInteractionLog {
  sessionId: "xyz123",
  
  // Phase 1: Discovery Browsing (before selection)
  carouselInteractions: [
    { cardName: "Investor Opportunities", action: "hover", timestamp: "..." },
    { cardName: "Investor Opportunities", action: "click", timestamp: "..." },
    { cardName: "Market Pulse", action: "view", timestamp: "..." }
  ],
  
  sectionViewedBeforeSelection: [
    { section: "Market Intelligence", scrollDepth: "50%", timeSpent: "45s" },
    { section: "Legal Risk Matrix", scrollDepth: "25%", timeSpent: "15s" }
  ],
  
  // Phase 2: After Selection
  selectedGoal: "capital_appreciation",
  selectedTimeline: "short_term",
  
  // Track what user explores after selection
  sectionsViewedAfterSelection: [
    { section: "Ranked Localities", clicked: true, timeSpent: "2m" },
    { section: "Market Intelligence", expanded: true, timeSpent: "3m" },
    { section: "ROI Projection", calculated: true, timeSpent: "1m" }
  ],
  
  // Track which expandable sections opened
  expandedSections: [
    { locality: "Hingna", section: "Market Intelligence", timeSpent: "2m" },
    { locality: "Wardha Road", section: "Legal Deep Dive", timeSpent: "1.5m" }
  ]
}
```

### Use Tracking Data For:
1. **Improve Future Recommendations** - Show users content similar to what they engaged with
2. **A/B Testing** - Which content resonates with which user types
3. **Predict Intent** - User clicks "Investor Opportunities" → likely to select "Capital Appreciation" or "Rental Income"
4. **Optimize Content** - Sections with low engagement can be redesigned or repositioned
5. **Personalize Future Visits** - Returning user sees content matching their previous interests
