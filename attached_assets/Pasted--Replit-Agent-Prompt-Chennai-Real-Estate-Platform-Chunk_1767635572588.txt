# Replit Agent Prompt: Chennai Real Estate Platform - Chunk 4 (Lead Capture & Behavioral Intelligence System)

## Project Overview
Build a **comprehensive lead capture and behavioral intelligence system** for a Chennai real estate platform. This system tracks ALL user behavior (without forced login), captures leads through 6 different touchpoints, scores lead quality using intent algorithms, and provides market intelligence through an admin dashboard.

**Core Philosophy**: 
- No forced authentication - users browse freely
- WhatsApp-first contact (95%+ open rate in India)
- Capture data from every interaction
- Multi-touch lead capture (6 different modals)
- AI-ready data structure for future recommendations

---

## Technical Stack
- **Frontend**: React 18+ with Tailwind CSS
- **Backend**: Node.js with Express
- **Database**: PostgreSQL (Supabase)
- **Real-time**: Socket.io (optional for live dashboard updates)
- **Charts**: Recharts or Chart.js
- **Storage**: LocalStorage for session tracking
- **API**: RESTful endpoints

### PART 1: Behavioral Event Tracking (Silent Background Tracking)

#### 1.1 Frontend Event Tracking System

Create `utils/tracking.js`:

```javascript
// Track every user action without disrupting UX
const tracking = {
  // Initialize session on page load
  initSession() {
    let sessionId = localStorage.getItem('sessionId');
    if (!sessionId) {
      sessionId = `session_${Date.now()}_${Math.random().toString(36).substr(2, 9)}`;
      localStorage.setItem('sessionId', sessionId);
    }
    return sessionId;
  },

  // Track property view
  trackPropertyView(propertyId, timeSpent, scrollDepth) {
    sendEvent({
      event_type: 'property_view',
      property_id: propertyId,
      event_data: { timeSpent, scrollDepth }
    });
  },

  // Track property save
  trackPropertySave(propertyId, fromPage) {
    sendEvent({
      event_type: 'property_save',
      property_id: propertyId,
      event_data: { fromPage }
    });
  },

  // Track filter application
  trackFilterApplied(filters) {
    sendEvent({
      event_type: 'filter_applied',
      event_data: { filters }
    });
  },

  // Track page visit
  trackPageVisit(pagePath, timeSpent) {
    sendEvent({
      event_type: 'page_visit',
      event_data: { pagePath, timeSpent }
    });
  }
};

async function sendEvent(eventData) {
  const sessionId = tracking.initSession();
  await fetch('/api/events/track', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      session_id: sessionId,
      ...eventData,
      timestamp: new Date().toISOString()
    })
  });
}
```

**Track these specific actions:**
- Property card viewed (on Find Properties page)
- Property detail page opened (track time spent)
- Property saved/bookmarked
- Property shared (WhatsApp/Email/Link)
- Filter applied/changed
- Search performed
- Locality guide page visited
- Scroll depth on property detail (how far they scrolled)
- CTA clicks (Schedule Visit, Ask Expert, etc.)
- Exit intent (mouse leaving viewport)

### PART 3: Intent Scoring Algorithm

Create `utils/intentScoring.js`:

```javascript
function calculateIntentScore(behaviorProfile, searchFilters, source) {
  let score = 0;

  // Time spent (max 3 points)
  const timeSpentMinutes = behaviorProfile.time_spent_total / 60;
  if (timeSpentMinutes > 10) score += 3;
  else if (timeSpentMinutes > 5) score += 2;
  else if (timeSpentMinutes > 2) score += 1;

  // Properties saved (max 2 points)
  const savedCount = behaviorProfile.properties_saved?.length || 0;
  if (savedCount >= 5) score += 2;
  else if (savedCount >= 3) score += 1.5;
  else if (savedCount >= 1) score += 1;

  // Filter refinements (max 2 points)
  const refinements = behaviorProfile.filter_refinements || 0;
  if (refinements >= 7) score += 2;
  else if (refinements >= 4) score += 1.5;
  else if (refinements >= 2) score += 1;

  // Return visits (max 1.5 points)
  const returnVisits = behaviorProfile.return_visits || 0;
  if (returnVisits >= 3) score += 1.5;
  else if (returnVisits >= 2) score += 1;
  else if (returnVisits >= 1) score += 0.5;

  // Custom remarks provided (max 1 point)
  if (investmentProfile?.custom_remarks && investmentProfile.custom_remarks.length > 20) {
    score += 1;
  }

  // Source quality (max 0.5 points)
  if (source === 'missing_property') score += 0.5;
  else if (source === 'filter_search') score += 0.3;
  else if (source === 'comparison_request') score += 0.2;

  // Normalize to 0-10 scale
  return Math.min(score, 10).toFixed(1);
}

function classifyIntentLevel(intentScore) {
  if (intentScore >= 7.5) return 'high';
  if (intentScore >= 4.5) return 'medium';
  return 'low';
}

function estimateConversionProbability(intentScore, source) {
  let baseProbability = intentScore / 10;
  
  // Source multipliers
  if (source === 'missing_property') baseProbability *= 1.2;
  else if (source === 'filter_search') baseProbability *= 1.1;
  else if (source === 'exit_intent') baseProbability *= 0.7;
  
  return Math.min(baseProbability, 0.95).toFixed(2);
}
```
