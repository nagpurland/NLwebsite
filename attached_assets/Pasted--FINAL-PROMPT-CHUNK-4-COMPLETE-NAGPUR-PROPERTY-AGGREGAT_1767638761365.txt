## SECTION 3: DATA QUALITY & DEDUPLICATION

### Task 3.1: IDENTIFY DUPLICATE PROPERTIES

**Problem:** Same property listed on multiple portals

**Example:**
- 99acres: "Godrej Orchard Estate, 1500 sqft, ₹45L, Besa"
- MagicBricks: "Godrej Orchard, Plot 1500, ₹45L, Besa"
- Housing.com: "Godrej Orchard Estate, Besa, ₹45 Lakhs"
= SAME PROPERTY (listed 3 times)

**How to Detect:**
- Title similarity: Same property name?
- Location match: Same area?
- Price match: Within ±10%?
- Size match: Within ±10%?
- If all match → DUPLICATE

**Merging Process:**
1. Keep one master record
2. Add all sources: "Listed on 99acres, MagicBricks, Housing.com"
3. Combine all images (15+ photos from 3 sources)
4. Keep lowest price (best deal for buyer)
5. Link to all original listings (attribution)
6. Update "Listed On" badge

**Expected Result:**
- Raw scraped: 2500 properties (if scraping all 3 portals)
- After dedup: ~500 unique properties
- Each property on avg: 3-4 source listings

### Task 3.2: QUALITY SCORING SYSTEM

**10/10 (Premium Quality)**
- Complete title & description
- 5+ high-quality images
- Price verified
- Legal status confirmed
- Listed <7 days ago

**7-9/10 (Good Quality)**
- Complete data
- 3-4 images
- Price reasonable
- Some legal info

**5-6/10 (Moderate Quality)**
- Partial data (missing some fields)
- 2-3 images
- Price estimated

**<5/10 (Low Quality - Flag for Review)**
- Incomplete data
- <2 images
- Mark for manual verification

**Auto-Scoring Formula:**
- Count filled data fields ÷ Total possible fields × 10
- Example: 7 of 10 fields filled = 7/10 score

**Use on Platform:**
- Sort properties by quality (high quality first)
- Show quality star rating (⭐⭐⭐ = 7/10)
- Buyers trust high-score properties more
