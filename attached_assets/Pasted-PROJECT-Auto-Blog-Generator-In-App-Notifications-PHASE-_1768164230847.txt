PROJECT: Auto Blog Generator + In-App Notifications

PHASE 1 MVP (Blog + In-App):
├─ Gemini Pro: FREE (12-point guides, case studies, tips, Q&A)
├─ Perplexity Pro: $5/month (market trends, legal updates)
└─ Publish to: Blog website + In-app notifications only

ADMIN PANEL FEATURES:

1. Blog Generator:
   ├─ Content type dropdown (12-point-guide, case-study, market-trend, etc.)
   ├─ Input fields: locality, topic, tone
   ├─ AI router: Gemini (free) or Perplexity (budget-tracked)
   ├─ Draft preview + edit capability
   ├─ Scheduling (date + time)
   └─ [Generate] [Approve] [Schedule] buttons

2. In-App Notifications:
   ├─ Auto-create notification when blog publishes
   ├─ Notification text: "📍 New Guide: [Blog Title]"
   ├─ Shows on checklist page as toast/banner
   ├─ Click → opens blog in new tab
   └─ No user unsubscribe needed (always shown)

3. Budget Tracker:
   ├─ Perplexity budget: $5.00/month
   ├─ Used: $X.XX
   ├─ Remaining: $Y.YY
   └─ Auto-alert: "Switch to Gemini only when budget < $1"

4. Publishing Workflow:
   ├─ Admin generates blog (30 sec)
   ├─ Approves draft (2 min edit)
   ├─ Clicks "Publish Now" or "Schedule for [date/time]"
   ├─ System auto-publishes to:
   │  ├─ /blog/[post-name] (website)
   │  └─ In-app notification (checklist page)
   └─ DONE ✓

PUBLISHING SCHEDULE:
├─ Monday: 1 guide (Gemini)
├─ Tuesday: 1 case study (Gemini)
├─ Wednesday: 1 market trend (Perplexity)
├─ Thursday: 1 Q&A (Gemini)
├─ Friday: 1 legal update (Perplexity)
├─ Saturday: 1 tips/hacks (Gemini)
└─ Sunday: 1 recap/trending (Gemini)

TOTAL: 7 blogs/week = 28 blogs/month
├─ 20 Gemini blogs (FREE)
└─ 8 Perplexity blogs (~$4/month) ✓ Within budget

TECH IMPLEMENTATION (Replit):

Backend (Flask/Python):
├─ Store API keys in Replit Secrets
├─ Create /api/generate-blog endpoint
│  ├─ Router: Use Gemini or Perplexity based on content type
│  ├─ Track Perplexity spend
│  └─ Return blog draft JSON
├─ Create /api/publish-blog endpoint
│  ├─ Save blog to database
│  ├─ Save to /blog/[slug] folder
│  └─ Create in-app notification record
└─ Create /api/budget endpoint (track spending)

Frontend (React/Vue):
├─ Admin form:
│  ├─ Content type selector
│  ├─ Locality input
│  ├─ Topic input
│  ├─ Tone selector (casual/professional)
│  └─ [Generate] button
├─ Draft preview:
│  ├─ Generated blog text (editable textarea)
│  ├─ Auto-generated SEO meta tags
│  ├─ Schedule date/time picker
│  └─ [Approve & Publish] button
└─ Budget dashboard:
   ├─ Monthly budget bar
   ├─ Blogs generated count
   └─ Cost tracker

Database (Simple):
├─ blogs table:
│  ├─ id, title, slug, content, meta_description
│  ├─ published_date, content_type, locality
│  └─ views_count, clicks_count
└─ notifications table:
   ├─ id, blog_id, notification_text
   ├─ published_date, is_active
   └─ clicks_count

In-App Notification Display:
├─ On checklist page, show notification banner:
│  ├─ "📍 New Guide: How to Verify Ownership in Nagpur South"
│  ├─ [Read Guide] button
│  └─ Auto-dismiss after 5 seconds or click X
└─ Also show in notification center (if users access it)

WORKFLOW EXAMPLE:
Admin → Clicks "Generate Blog"
  ↓
Form: Content Type = "12-Point Guide", Locality = "Nagpur South", Topic = "Ownership"
  ↓
AI generates blog (Gemini) in 30 sec
  ↓
Admin reviews draft, clicks "Approve"
  ↓
Blog saves to /blog/how-to-verify-ownership-nagpur-south
  ↓
In-app notification created: "📍 New Guide: How to Verify Ownership"
  ↓
Checklist users see notification → Click → Open blog in new tab
  ↓
Users reading blog → See "Back to Checklist" button
  ↓
Complete flow ✓
