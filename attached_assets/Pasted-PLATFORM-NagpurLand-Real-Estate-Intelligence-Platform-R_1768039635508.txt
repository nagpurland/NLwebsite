=== PART 3: DATABASE SCHEMA ===

Web Intelligence will store data in these collections/tables:

TABLE 1: NEWS_ARTICLES
Columns:
├─ id (unique)
├─ title (news headline)
├─ content (article text - first 300 words)
├─ source (Times of India, Nagpur Today, etc)
├─ source_url (link to original article)
├─ published_date (when published)
├─ scraped_date (when we scraped it)
├─ category (Infrastructure / Jobs / Market / Legal / Policy / Other)
├─ locality (MIHAN / Besa / Wardha Road / Hingna / Multiple / City-wide)
├─ sentiment (Positive / Negative / Neutral)
├─ impact_level (High / Medium / Low)
├─ keywords (tags: metro, jobs, IT park, property, prices, etc)
├─ summary (AI-generated one-liner summary)
└─ processed (true/false - whether analyzed)

Example row:
{
  id: "news_2026_0110_001",
  title: "Metro Phase 2 Groundbreaking Ceremony Scheduled for March 2026",
  content: "Nagpur Metro authority announced...",
  source: "Times of India",
  source_url: "toi.com/article/...",
  published_date: "2026-01-10",
  scraped_date: "2026-01-10 02:15 AM",
  category: "Infrastructure",
  locality: "MIHAN",
  sentiment: "Positive",
  impact_level: "High",
  keywords: ["metro", "MIHAN", "infrastructure", "jobs"],
  summary: "Metro Phase 2 groundbreaking in March will transform MIHAN area",
  processed: true
}


TABLE 2: SOCIAL_POSTS
Columns:
├─ id (unique)
├─ platform (Twitter / Reddit / Facebook / LinkedIn)
├─ author (username/handle)
├─ content (post text)
├─ post_date (when posted)
├─ scraped_date (when we scraped it)
├─ engagement (likes, comments, shares, retweets count)
├─ sentiment (Bullish / Bearish / Neutral)
├─ topic (Prices / Locality / Metro / Jobs / Legal / Infrastructure / Buying Experience)
├─ locality_mentioned (MIHAN / Besa / etc)
├─ viral (true/false - if highly engaged)
├─ post_url (link to original post)
└─ processed (true/false)

Example row:
{
  id: "social_2026_0110_045",
  platform: "Twitter",
  author: "@buyer_nagpur",
  content: "Just closed deal in MIHAN for ₹45L. Metro in 6 months will make this investment gold! #MIHANMetro",
  post_date: "2026-01-10 10:30 AM",
  scraped_date: "2026-01-10 02:45 AM",
  engagement: { likes: 245, retweets: 89, replies: 34 },
  sentiment: "Bullish",
  topic: "Prices, Metro",
  locality_mentioned: "MIHAN",
  viral: true,
  post_url: "twitter.com/...",
  processed: true
}


TABLE 3: JOB_MARKET
Columns:
├─ id (unique)
├─ company_name (company hiring)
├─ job_category (IT / Manufacturing / Services / Retail / Other)
├─ number_of_openings (X jobs)
├─ salary_range (if available)
├─ location/locality (MIHAN / city / other)
├─ posted_date (when job posted)
├─ scraped_date (when we scraped it)
├─ job_source (LinkedIn / Naukri / company website)
├─ job_url (link to posting)
├─ trend (Increasing / Stable / Decreasing)
├─ month_over_month_change (% change from last month)
└─ processed (true/false)

Example row:
{
  id: "job_2026_0110_001",
  company_name: "Infosys",
  job_category: "IT",
  number_of_openings: 50,
  salary_range: "₹6L - ₹12L per annum",
  location: "MIHAN, Nagpur",
  posted_date: "2026-01-08",
  scraped_date: "2026-01-10 03:15 AM",
  job_source: "LinkedIn",
  job_url: "linkedin.com/jobs/...",
  trend: "Increasing",
  month_over_month_change: "+40%",
  processed: true
}


TABLE 4: INFRASTRUCTURE_PROJECTS
Columns:
├─ id (unique)
├─ project_name (name of project)
├─ project_type (Metro / Road / IT Park / Mall / Hospital / School)
├─ current_status (% completed)
├─ timeline_to_completion (X months away)
├─ launch_date (estimated launch date)
├─ affected_localities (which areas impacted)
├─ expected_job_impact (number of jobs expected)
├─ expected_property_appreciation (% price increase expected)
├─ investment_amount (project cost)
├─ last_update_date (when we last checked)
├─ source (government press, MIHAN authority, municipal)
└─ processed (true/false)

Example row:
{
  id: "project_2026_metro_phase2",
  project_name: "Nagpur Metro Phase 2",
  project_type: "Metro",
  current_status: 60,
  timeline_to_completion: 6,
  launch_date: "2026-12-31",
  affected_localities: ["MIHAN", "Besa", "Wardha Road"],
  expected_job_impact: 5000,
  expected_property_appreciation: 15-20,
  investment_amount: "₹3,000 Cr",
  last_update_date: "2026-01-10",
  source: "Nagpur Metro Rail Corporation",
  processed: true
}


TABLE 5: LEGAL_DISPUTES
Columns:
├─ id (unique)
├─ dispute_type (Land Dispute / Title Issue / Encroachment / Environmental / Building Code)
├─ locality (area where dispute is)
├─ case_number (court case reference)
├─ filed_date (when case filed)
├─ current_status (Pending / Resolved / Dismissed)
├─ description (details of dispute)
├─ impact_level (High - affects many properties / Medium / Low)
├─ last_update_date (when we last checked)
├─ source (District Court / Municipal Corp)
└─ processed (true/false)

Example row:
{
  id: "legal_2026_0110_001",
  dispute_type: "Encroachment",
  locality: "South Nagpur",
  case_number: "SC-2025-1234",
  filed_date: "2024-06-15",
  current_status: "Pending",
  description: "Encroachment on government land by private builder",
  impact_level: "High",
  last_update_date: "2026-01-08",
  source: "District Court of Nagpur",
  processed: true
}


TABLE 6: MARKET_INTELLIGENCE (GENERATED DAILY)
Columns:
├─ id (unique)
├─ report_date (when report generated)
├─ locality (specific area or "All Nagpur")
├─ market_temperature (HOT / WARM / COOLING)
├─ price_trend_30d (% change past 30 days)
├─ price_trend_90d (% change past 90 days)
├─ avg_price (₹ amount)
├─ avg_price_per_sqft (₹ amount)
├─ new_listings_count (number added this week)
├─ delisted_count (number removed this week)
├─ days_to_sell_avg (average days on market)
├─ employment_jobs_count (active job openings)
├─ employment_trend (increasing / stable / decreasing)
├─ infrastructure_status (list of projects and % complete)
├─ news_sentiment_positive (%)
├─ news_sentiment_negative (%)
├─ news_sentiment_neutral (%)
├─ social_sentiment (bullish / bearish / neutral)
├─ legal_disputes_count (number of active disputes)
├─ buying_clarity_score (1-10)
├─ verdict (text summary)
├─ processed (true/false)
└─ created_at (timestamp)

Example row:
{
  id: "intel_2026_0110_mihan",
  report_date: "2026-01-10",
  locality: "MIHAN",
  market_temperature: "HOT",
  price_trend_30d: 8.5,
  price_trend_90d: 18.2,
  avg_price: 4500000,
  avg_price_per_sqft: 3000,
  new_listings_count: 95,
  delisted_count
