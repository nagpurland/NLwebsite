PART 13: DEDUPLICATION ALGORITHM (IN DETAIL)
Problem: Same property on 99acres, MagicBricks, Housing.com

Example:

text
99acres: "Godrej Orchard Estate, Plot 1500sqft, Besa, ₹45L"
MagicBricks: "Godrej Orchard Estate, 1500sqft Plot, Besa, ₹45L"
Housing.com: "Godrej Orchard Estate Besa ₹45L Plot"
Solution Algorithm:

text
FOR each property_A in database:
  FOR each property_B in new_scraped_data:
    
    CALCULATE similarity score:
    ├─ Title match: 80%?
    ├─ Location match (area_name): exact?
    ├─ Price match: within ±10%?
    ├─ Area size match: within ±10%?
    
    IF (title_similarity > 80%) AND 
       (location_match == true) AND 
       (price_match == true) AND 
       (area_size_match == true):
      
      → DUPLICATE FOUND
      → MERGE:
         - Keep lowest price
         - Combine images (property_A images + property_B images)
         - Add source: "Listed on 99acres, MagicBricks, Housing.com"
         - Add original_urls: [url_99acres, url_magicbricks, url_housing]
         - Keep unified property_id
         
      ELSE:
        → NEW PROPERTY
        → INSERT into database
